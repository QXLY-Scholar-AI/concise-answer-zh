# 词语选择与适用边界

## 词典怎样用于写作

原标准词典包含875个批准词和1274个未批准词，另允许符合类别的技术名词和技术动词。词条是否可用，不仅看拼写，还要看词性、批准意义、词形、语境限制和条目中的帮助说明。不能把词典压成一张“用这个词替换那个词”的表。

检查英文词语时按以下判断顺序操作：

1. 词在词典中且获准：核对当前词性、词形和意义，再看相关示例及语境限制；全部相符才使用。
2. 词未获准：阅读候选替代及意义，按当前语境选择。相同词性且意义不变时可替换；需要改变词性或关系时重组句子。
3. 词未收录，或只能在专业语境使用：检查技术名词、技术动词类别及项目术语表。符合条件时记录术语身份再使用；不能因为词未收录就否定真实专业名称。
4. 查不到依据或拿不准含义：保留待核实状态，查原文或询问，不根据常用英语印象宣称符合STE。

这是按原标准PDF第131—144页的说明与选词流程整理。英文合规检查还需完整词典和适用行业文件，本中文Skill不自动给出认证结论。

## 四列词条必须合起来看

- 第一列提供词头和词性；大写与小写表达批准状态，不能凭词在例句中大写判定。
- 第二列给出批准意义或候选替代。替代建议可能换了词性，也可能是短语，不能机械对换。
- 第三列演示如何在句子中保持意思；它是一种写法，不是所有场景的固定模板。
- 第四列展示不符合STE的用法，可能同时含多个问题，不应仅替换被圈出的词就认定整句已合规。

帮助说明还可能限制词的方向、其他意义、仅可出现的情境，或指出无需替代而可直接省去的部分。动词有时涉及及物/不及物的不同含义；过去分词、情态动词、形容词比较形式也需分别确认。

## 对中文实际采用什么

采用的是选词方法：意思明确、语境正确、术语稳定、专业名称有依据，改词后复核整句。具体英文词头和词性许可不转成中文禁词表；英文中的未批准词，也不表示其中文译法应被禁止。

项目已有中文术语表时优先使用。一个短名称无法唯一识别对象时，补上必要限定；专业名称本身已明确时，不追加重复释义。避免为了词汇变化而更换同一对象的称呼。

## 不机械迁移的英文要求

| 英文原要求 | 中文处理 |
|---|---|
| 程序句20词、描述句25词 | 不换算为汉字上限；按意思和理解负担拆句 |
| 多词名词原则上三词以内 | 拆开含糊的修饰链；正式名称不硬拆 |
| 段落最多六句 | 按中心和阅读负担分段，不逐句另起行 |
| 规定的时态、分词和-ing用法 | 保留中文的时间、状态和动作意义，不套英语词形限制 |
| 词性与受限词义许可 | 中文按自身语法和专业含义判断 |
| 英语冠词、所有格、连字符和计词方法 | 不机械添加“该、此、一个”，不造连字符词来凑形式 |
| 英语STE不用分号 | 中文按实际逻辑和目标格式选择标点 |
| 默认美式拼写 | 英文名称按项目要求和原始引用保留 |
| 英语词典中的安全情态词替代 | 不把中文“可能、应当、必须”无条件互换 |

## 原标准与本Skill的职责

原标准约束技术英语的表达，强调准确理解和执行；它不统一规定字体、编号、单位展示或所有文体的篇幅。本Skill将其写作思想用于中文稿件，并增加用户要求的自动判定和发送前精简流程。完整规则对应保留在另一份参考中，避免把英文硬性限制误当成中文标准。
